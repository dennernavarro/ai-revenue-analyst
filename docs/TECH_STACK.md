# Tech stack

Versions are the locked ones (`uv.lock`, `frontend/package.json`).

## Backend

| Layer | Choice | Version | Why |
|---|---|---|---|
| Language | Python | ≥ 3.11 (3.12 in Docker) | Ecosystem for LLM tooling |
| Package manager | uv | — | Fast, lockfile (`uv.lock`), `uv sync --frozen` in CI/Docker |
| API | FastAPI + Uvicorn | 0.163.0 / 0.54.0 | Typed REST, auto docs at `/docs`, streaming |
| Models / validation | Pydantic + pydantic-settings | 2.14.3 | Domain types, API schemas, `.env` config (`RA_` prefix) |
| Agent framework | LangChain (`create_agent`) | 1.5.0 | Chat agent (ReAct loop over tools) |
| Workflows | LangGraph | 1.2.22 | Pricing review graph, `interrupt()` for human approval |
| Deep agent | deepagents | 0.7.38 | Planning (`write_todos`), subagents (`task()`) |
| Persistence | langgraph-checkpoint-sqlite | 3.1.3 | Conversation + paused-review checkpoints in `.state/` |
| LLM providers | langchain-openai (OpenRouter), langchain-anthropic | 1.8.0 / 1.7.10 | Vendor is config: `RA_MODEL=openrouter:…`, `anthropic:…`, `ollama:…` |
| Tracing / evals | LangSmith (optional) | 0.14.17 | Experiments for `evals.py --langsmith` |

Default model: `openrouter:openai/gpt-4o-mini`.

## Frontend

| Choice | Version |
|---|---|
| React + React DOM | ^18.3.1 |
| Vite + @vitejs/plugin-react | ^5.4.11 / ^4.3.4 |
| react-markdown + remark-gfm | ^10.1.0 / ^4.0.1 (chat replies) |

Built to `frontend/dist`, served by the API at `/ui`. Dev server: Vite on
5173 with a proxy to the API.

## Data

- Mock PMS (`pms/mock.py`) over `data/*.json`, generated by a seeded booking
  simulator (`datagen.py`, `scripts/generate_data.py`).
- History: 2025-01-01 → 2027-03-31, simulated "today" 2026-11-01.

## Tooling and delivery

| Concern | Tool |
|---|---|
| Lint | ruff 0.17.5 (line length 100) |
| Tests | pytest 9.2.0 (offline, fake models) |
| CI | GitHub Actions: `uv sync --frozen` → `ruff check .` → `pytest -q` |

## Adding a dependency

Prefer the standard library or what's already here. A new dependency needs a
line in the PR saying what it replaces and why a few lines of code won't do;
add it with `uv add` so `uv.lock` updates.
